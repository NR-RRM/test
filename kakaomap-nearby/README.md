# 내 맛집 반경 검색

카카오맵 즐겨찾기(공유 폴더)에 저장한 장소 중, 입력한 위치 주변에 있는 곳을 거리순으로 보여주는 HTML 한 장입니다.

- `index.html`: 이 파일 하나만 열면 됩니다. 데이터가 안에 들어 있어 서버나 API 키가 필요 없습니다.
- 위치 입력: 역 이름(강남역), 동 이름(방배동), 도로명(을지로), 저장한 가게 이름, 또는 `37.497, 127.027` 같은 좌표
- 반경(300m~5km), 폴더, 이름·메모 키워드로 거를 수 있습니다.

## 데이터 갱신

```
pip install pyproj
python3 update.py
```

`folders.txt`에 있는 공유 링크로 최신 목록을 다시 받아 `index.html`을 새로 만듭니다.
카카오 비공식 웹 API를 쓰므로 카카오가 구조를 바꾸면 동작하지 않을 수 있습니다.
지명 데이터(`data/gazetteer.json`)는 © OpenStreetMap contributors (ODbL)입니다.
